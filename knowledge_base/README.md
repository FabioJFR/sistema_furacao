# Base de Conhecimento

Esta pasta guarda documentos de referencia do projeto para consulta interna e pela AI da plataforma.

## Estrutura

- `drone/`
  - especificacoes de drone proprio
  - sensores
  - integracao com a plataforma
- `geologia/`
  - documentos tecnicos de geologia
  - procedimentos
  - referencias de campo
- `ia/`
  - documentos sobre AI, OCR, analise visual e chat interno
- `plataforma/`
  - estrutura funcional da plataforma
  - permissões, planos e features
  - preparação para ambiente online e operação futura
- `pdf/`
  - biblioteca documental de apoio
  - PDFs e outros ficheiros adicionados manualmente
  - sempre que possível, acompanhar formatos não textuais com um `.txt` de apoio com o mesmo nome
  - exemplo: `manual_operacao.pdf` + `manual_operacao.txt`

## Regras

- guardar sempre versoes editaveis quando possivel, por exemplo `.md`, `.txt` ou `.json`
- guardar tambem versoes finais em `.pdf` quando fizer sentido
- para leitura mais fiável pela AI, formatos não textuais devem ter um `.txt` com o mesmo nome na mesma pasta
- usar nomes de ficheiro claros e estaveis
- separar o conteudo por tema para facilitar consulta manual e pela AI
