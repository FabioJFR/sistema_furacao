{% trans "Tutorial: Novo Registo Diário" %}

{% trans "Guia completo para criar, preencher, editar e apagar um registo diário com informação operacional e técnica do turno." %}

{% if is_empregado_user %} {% trans "Abrir Meus Registos" %} {% trans "Novo Registo" %} {% endif %} {% if is_admin_user %} {% trans "Abrir Registos de Produção" %} {% endif %}

{% trans "O que é um Registo Diário" %}

{% trans "É o registo principal do trabalho realizado no turno. Guarda horas, pausas, metros furados, observações, anexos e a ficha técnica detalhada quando necessário." %}

{% trans "Quando usar" %}

{% trans "Use um registo por turno efetivamente realizado. Se o turno foi planeado, selecione o planeamento para herdar automaticamente projeto, furo, data e horário base." %}

{% trans "Passo 1. Abrir a página de novo registo" %}

{% trans "O empregado entra em Meus Registos e clica em Novo Registo. A empresa pode abrir o mesmo fluxo a partir da área de Registos de Produção." %}

{% trans "Se existirem turnos planeados para a data, eles aparecem no topo para seleção rápida." %}

{% trans "Passo 2. Selecionar o Planeamento Turno" %}

{% trans "Ao escolher um planeamento, o sistema preenche automaticamente a data, o projeto, o furo e as horas base do turno. Isto reduz erros e liga o registo ao turno correto." %}

{% trans "Se não existir planeamento, o registo também pode ser preenchido manualmente." %}

{% trans "Passo 3. Preencher o Registo Operacional" %}

{% trans "Nesta primeira secção preencha as horas do turno, pausas, horas de paragem, tipo de paragem, metros furados, foto do relatório e observações gerais." %}

  • {% trans "Horas de paragem só devem ser usadas quando houve interrupção real." %}
  • {% trans "Tipo de paragem ajuda a distinguir responsabilidade entre cliente e empresa." %}
  • {% trans "Observações servem para notas operacionais rápidas do turno." %}

{% trans "Passo 4. Preencher a Informação Técnica" %}

{% trans "A ficha técnica do turno é opcional, mas deve ser usada quando queres guardar o relatório técnico com mais detalhe." %}

  • {% trans "Informação: cliente, sonda, torre, bombas, estaleiro, número do relatório, turno e valores principais." %}
  • {% trans "Avanço e recuperação: adicionar as furadas do turno uma a uma, com início, fim, avanço, recuperação, rocha e descrição." %}
  • {% trans "Operações e ocorrências: adicionar linhas com o tipo de ocorrência e o intervalo horário de cada uma." %}
  • {% trans "Polímeros: adicionar os polímeros usados, um a um." %}
  • {% trans "Equipa: adicionar os elementos da equipa com função, nome e horas trabalhadas." %}

{% trans "Passo 5. Adicionar listas dinâmicas" %}

{% trans "Nas secções Furadas, Operações/Ocorrências e Equipa, os dados são adicionados em linhas. Depois de preencher os campos, clica no botão + para guardar a linha na lista." %}

{% trans "Também podes editar uma linha já criada ou removê-la antes de guardar o registo final." %}

{% trans "Passo 6. Guardar o registo" %}

{% trans "Depois de rever as secções preenchidas, clica em Guardar Registo. O sistema grava o registo operacional e, se existir conteúdo técnico, guarda também a informação técnica no próprio registo." %}

{% trans "Se a ficha técnica estiver vazia, o sistema guarda apenas o registo operacional." %}

{% trans "Passo 7. Editar um registo existente" %}

{% trans "Na lista de registos, abre o registo pretendido e usa o botão Editar ou Corrigir. Aí podes atualizar horas, metros, observações e também toda a parte técnica do turno." %}

{% trans "As listas dinâmicas mantêm as linhas já criadas, permitindo corrigir uma furada, uma ocorrência ou um elemento da equipa sem voltar a escrever tudo." %}

{% trans "Passo 8. Apagar um registo" %}

{% trans "Se um registo tiver sido criado por engano, abre a lista correspondente e usa a ação de apagar no registo certo. O sistema pede confirmação antes de remover." %}

{% trans "Apaga apenas quando o registo foi mesmo lançado por erro. Se o objetivo for corrigir conteúdo, o mais seguro é editar." %}

{% trans "Boas práticas" %}

  • {% trans "Seleciona sempre o planeamento correto quando existir." %}
  • {% trans "Regista cada furada e ocorrência em linhas separadas para manter o histórico limpo." %}
  • {% trans "Usa observações para contexto curto e descrição técnica nas secções certas." %}
  • {% trans "Revê horas, metros e listas antes de guardar." %}
  • {% trans "Prefere editar em vez de apagar, para reduzir perda de histórico." %}

{% trans "Dúvidas comuns" %}

  • {% trans "Se os turnos não aparecerem, verifica se existe planeamento para a data ou se o turno ainda está sem empregado atribuído." %}
  • {% trans "Se um campo técnico não se aplicar, pode ficar vazio." %}
  • {% trans "Se a lista dinâmica não mostrar a linha, confirma se clicaste no botão + depois de preencher os campos." %}

{% trans "Quem deve usar" %}

{% trans "Este módulo é mais útil para contas de empresa e responsáveis operacionais. Centraliza conformidade documental, prevenção de incidentes e controlo de ações com prazo." %}

{% trans "Objetivo principal" %}

{% trans "Detetar riscos cedo, registar evidências, acompanhar correções e perceber rapidamente onde a empresa está a falhar mais." %}

{% trans "Passo 1. Registar a base operacional" %}

{% trans "Comece por lançar checklists HSE, incidentes e auditorias. Estes registos alimentam os indicadores principais e criam a base para decisões futuras." %}

{% trans "Sugestão prática: use checklists para rotina, incidentes para ocorrências reais e auditorias para validações mais formais." %}

{% trans "Passo 2. Criar ações com responsável e prazo" %}

{% trans "Quando encontrar um problema, crie uma ação corretiva ou preventiva. Defina prioridade, responsável, data-limite e o projeto associado sempre que possível." %}

{% trans "Isto permite ao painel calcular vencimentos, SLA, taxa de fecho e previsão de incumprimento." %}

{% trans "Passo 3. Anexar evidências" %}

{% trans "Adicione fotografias, PDFs, relatórios ou outros anexos às checklists, incidentes, auditorias e ações. As evidências ajudam na validação, auditoria e fecho formal." %}

{% trans "Passo 4. Fechar corretamente as ações" %}

{% trans "Ao concluir uma ação corretiva, faça o fecho formal com resumo do que foi feito e validação de eficácia. Isso melhora a qualidade do histórico e dos relatórios executivos." %}

{% trans "Passo 5. Ler o dashboard de eficácia" %}

{% trans "O dashboard mostra taxa de fecho, SLA, tempo médio de resolução, responsáveis críticos, projetos com maior risco, snapshots comparativos e previsão de incumprimento." %}

  • {% trans "Use os filtros temporais Total, 7, 30 e 90 dias para perceber o comportamento recente." %}
  • {% trans "Use o drill-down por projeto e por responsável para abrir diretamente o detalhe das ações." %}
  • {% trans "Consulte os alertas automáticos para ações críticas vencidas e situações preventivas a vencer." %}

{% trans "Passo 6. Ajustar o score de risco" %}

{% trans "Em Definições, a empresa pode ajustar os pesos e limiares do score de incumprimento. Assim, o sistema pode dar mais importância a ações críticas, vencidas ou próximas do prazo, conforme a realidade da operação." %}

{% trans "Rotina recomendada" %}

  • {% trans "Diariamente: validar novos incidentes, checklists e alertas críticos." %}
  • {% trans "Semanalmente: rever ações abertas, vencidas e a vencer." %}
  • {% trans "Mensalmente: analisar o dashboard, comparar janelas e emitir relatório executivo." %}
