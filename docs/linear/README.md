# Linear Setup Pack

Este diretório foi preparado para ajudar a arrancar com o `Linear` sem experiência prévia.

## Ficheiros

- `linear_primeiros_passos.md`
  Guia simples para criar o workspace, a equipa, labels e projetos base.
- `linear_backlog_inicial.csv`
  Backlog inicial preparado a partir do estado atual da plataforma.
- `linear_estrutura_recomendada.md`
  Estrutura recomendada para usar o Linear neste projeto.

## Objetivo

O foco imediato não é organizar tudo para sempre. É começar a trabalhar com:

- um workspace limpo
- uma equipa principal
- projetos claros
- backlog inicial já separado por áreas

## Nota

Este pacote foi preparado localmente porque o ambiente atual não tem acesso direto ao teu workspace do Linear.
