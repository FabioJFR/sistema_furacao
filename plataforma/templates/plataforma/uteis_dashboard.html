Como usar os ficheiros descarregados

1. Arquivo e segurança: guarda os ficheiros exportados como cópia de segurança da base de dados da AI antes de alterações grandes ou antes de colocar a plataforma online.
2. Migração futura: usa os ficheiros `JSON` como referência para importar dados para outro ambiente, outra base de dados ou outro serviço AI.
3. Reaproveitamento: `AnaliseImagemAI`, `DeteccaoImagemAI`, `AnaliseZonaPresetAI` e `MemoriaTrabalhoAI` são úteis para a evolução técnica da AI, enquanto `Projeto`, `Furo`, `Medicao`, `RegistoDiarioEmpregado`, `RegistoDiarioFotoAmostra` e `Despesa` dão a memória operacional para aconselhamento futuro.
4. Pacote completo: o `ZIP` junta todos os conjuntos de dados e um `manifest.json`, sendo a melhor opção para backup completo deste módulo.
5. Leitura técnica: os ficheiros estão em `JSON`, por isso podem ser abertos em editor de texto, scripts Python, ferramentas ETL ou pipelines de treino/avaliação.
6. Antes de importar: confirma sempre compatibilidade de campos, relações e IDs com o ambiente de destino.
7. Limpeza: o botão `Limpar dados` apaga os registos do grupo selecionado diretamente da base de dados. Usa só quando tiveres um backup válido.
